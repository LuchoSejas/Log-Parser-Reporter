# Log Analyzer (Desktop App)

Aplicación de escritorio desarrollada en Python para el procesamiento, análisis y generación de reportes a partir de archivos de registro (`.log` / `.txt`). Diseñada con una interfaz gráfica adaptativa (responsive) inspirada en paneles de control corporativos.

---

## 🛠️ Tecnologías utilizadas

* **Lenguaje:** Python 3.x
* **GUI / Interfaz Gráfica:** Tkinter (Nativa)
* **Gestión de Archivos:** E/S estándar de Python (`open`, `close`, `read`)

---

## 🚀 Características principales

* **Interfaz Responsive:** La ventana y sus componentes se adaptan dinámicamente al cambiar el tamaño de la pantalla.
* **Procesamiento de Logs:** Lectura eficiente línea por línea para la extracción e identificación de eventos (`[INFO]`, `[WARNING]`, `[ERROR]`).
* **Métricas en tiempo real:** Visualización clara del conteo total de eventos mediante un dashboard intuitivo.
* **Carga interactiva:** Integración con el explorador de archivos nativo del sistema operativo.
